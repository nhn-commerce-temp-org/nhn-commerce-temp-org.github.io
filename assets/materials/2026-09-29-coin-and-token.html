코인과 토큰 개념 이해

둘을 가르는 기준은 단 하나, 자기 메인넷이 있는가

1. 코인이란? — 생성과정, 종류와 포크
2. 토큰이란? — 코인과의 차이, 생성과정(ERC-20), 종류
1

코인이란?

가상자산은 메인넷(독립된 블록체인 네트워크)을 가졌는지에 따라 코인과 토큰으로 나뉩니다. 자체 메인넷을 보유하고 독립된 생태계를 이루면 '코인'입니다. 비트코인과 이더리움이 대표적입니다.

비유로 보기

메인넷을 하나의 '나라'라고 생각하면, 코인은 그 나라의 법정화폐입니다. 비트코인이라는 나라의 화폐가 BTC, 이더리움이라는 나라의 화폐가 ETH입니다.

1-1. 코인 생성과정

네트워크를 유지·관리한 참여자에게 새 코인이 보상으로 지급됩니다. 방식은 크게 두 가지입니다.

작업증명 PoW · 비트코인

컴퓨터 연산으로 어려운 문제를 먼저 푼 사람이 블록을 추가하고 보상을 받습니다. 이것이 '채굴'입니다.

지분증명 PoS · 이더리움

코인을 일정량 이상 맡긴 사람이 검증자가 됩니다. 이더리움은 2022년 '머지' 업그레이드로 PoW에서 전환했습니다.

1-2. 코인 종류와 포크

코인은 처음부터 자체 블록체인으로 만들어지기도 하지만, 포크(fork)를 통해 기존 블록체인에서 갈라져 나오기도 합니다.

포크란? — 규칙을 바꿀 때 생기는 갈림길

블록체인은 모든 참여자가 같은 규칙을 지키기 때문에 하나의 장부로 유지됩니다. 규칙을 바꾸려 할 때 새 규칙을 따르는 쪽과 기존 규칙을 고수하는 쪽이 생기면 길이 갈라지는데, 이것이 포크입니다. 축구 규칙에 비유해 보겠습니다.

  • 소프트 포크 — "태클 규정을 더 엄격하게 하자." 규칙이 좁아지는 변경이라, 옛 규칙을 아는 심판이 봐도 문제가 없습니다. 기존과 호환되므로 체인이 갈라지지 않습니다.
  • 하드 포크 — "이제 손으로 공을 잡아도 된다." 옛 규칙으로는 명백한 반칙입니다. 기존과 호환되지 않아, 모두가 따르지 않으면 두 개의 체인으로 쪼개집니다.
실제 사례
  • 비트코인 캐시(BCH), 2017 — 블록 크기를 키워 처리 속도를 높이자는 쪽이 하드 포크로 갈라져 나왔습니다. 포크 시점의 BTC 보유자는 같은 수량의 BCH도 받았습니다.
  • 이더리움 클래식(ETC), 2016 — 'The DAO' 해킹 후 이더리움이 기록을 되돌리는 하드 포크를 하자, "기록은 되돌리면 안 된다"는 쪽이 기존 체인을 유지했습니다.

참고로 하드 포크를 해도 모두가 새 규칙을 따르면 체인은 하나로 유지되고, 단순한 업그레이드가 됩니다.

이후 스마트 컨트랙트 기능을 더해 블록체인 위에 앱과 토큰을 올릴 수 있게 한 이더리움이 등장했고, 속도·확장성·체인 간 연결성을 강화한 카르다노(ADA), 폴카닷(DOT) 등이 뒤를 이었습니다.

2

토큰이란?

토큰은 자체 메인넷 없이, 이미 존재하는 블록체인 위에서 특정 서비스가 목적에 맞게 발행한 가상자산입니다. 코인이 네트워크 운영에 쓰인다면, 토큰은 서비스가 정한 용도로 쓰입니다.

비유로 보기

코인이 나라의 법정화폐라면, 토큰은 그 나라 안의 백화점이나 놀이공원이 발행한 상품권·이용권입니다. 새 나라를 세울 필요 없이 기존 나라의 인프라를 빌려 씁니다.

결정적 차이 — 수수료를 무엇으로 내는가

이더리움 위에서는 무엇을 보내든 수수료(가스비)를 ETH로 내야 합니다. 지갑에 토큰이 100만 개 있어도 ETH가 0이면 토큰을 하나도 보낼 수 없습니다. 코인은 네트워크를 움직이는 연료이고, 토큰은 그 위에 실린 화물입니다.

또 코인 잔액은 블록체인이 직접 기록하지만, 토큰 잔액은 스마트 컨트랙트 안의 장부에 기록됩니다.

이름에 '코인'이 붙어도 토큰일 수 있다

스테이블코인 USDT·USDC나 상당수의 밈코인은 이더리움·솔라나 위에 발행된 토큰입니다. 판단 기준은 이름이 아니라 "자체 메인넷이 있는가"입니다.

2-1. 토큰 생성과정

이더리움에서는 스마트 컨트랙트로 토큰을 만듭니다. 이때 핵심 키워드가 ERC-20과 오픈제플린입니다.

ERC-20 = 토큰의 공통 규격

모든 가전제품이 같은 플러그를 쓰기 때문에 어느 콘센트에 꽂아도 작동합니다. ERC-20도 "토큰이라면 이 기능들을 이 이름으로 갖춰라"라는 공통 규격입니다. 덕분에 지갑과 거래소는 처음 보는 토큰도 바로 지원할 수 있습니다.

규격에는 잔액 조회(balanceOf), 전송(transfer), 사용 허락(approve) 같은 기능이 정해져 있습니다. DEX에서 스왑 전에 뜨는 '토큰 사용 승인'이 바로 approve입니다.

오픈제플린 = 검증된 조립 키트

스마트 컨트랙트는 배포 후 고치기 어렵고, 버그 하나가 해킹으로 이어집니다. 오픈제플린은 ERC-20 등의 표준을 미리 구현하고 보안 검증까지 마친 오픈소스 코드 모음입니다. 이름과 수량만 정해서 가져다 쓰면 됩니다.

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract StudyToken is ERC20 {                        // 오픈제플린 ERC20을 물려받음
    constructor() ERC20("Study Token", "STD") {      // 이름, 심볼
        _mint(msg.sender, 1000000 * 10 ** decimals()); // 100만 개 발행
    }
}

이 몇 줄을 이더리움에 배포(가스비는 ETH로 지불)하면 컨트랙트 주소가 생기고, 이것이 곧 토큰의 탄생입니다. 이런 표준은 이더리움 개선 제안(EIP)을 통해 누구나 제안할 수 있으며, NFT 표준인 ERC-721도 그중 하나입니다.

토큰의 진짜 신분증은 컨트랙트 주소

토큰은 누구나 쉽게 만들 수 있어서, 같은 이름의 가짜 토큰도 쉽게 등장합니다. 토큰을 살 때는 이름이 아닌 공식 컨트랙트 주소를 확인해야 합니다.

2-2. 토큰 종류

유틸리티 토큰서비스 이용권

서비스를 이용하는 데 필요한 토큰입니다. 걷기 게임 스테픈의 GST는 걸으며 얻고 게임 아이템에 씁니다. GST는 계속 발행되는 구조라 공급이 크게 늘며 가격이 급락했는데, 토큰 인플레이션의 대표 사례이기도 합니다.

대체불가토큰 (NFT)번호가 붙은 유일한 토큰

만 원권 지폐는 서로 바꿔도 같으니 '대체 가능', 좌석이 지정된 콘서트 티켓은 자리마다 가치가 다르니 '대체 불가'입니다. NFT는 디지털 자산에 고유값을 부여해 소유권을 증명합니다.

토큰증권 (STO)블록체인에 올린 증권

주식·채권 같은 증권을 토큰 형태로 발행한 것입니다. 형태는 새롭지만 투자자에게 수익 등의 권리를 약속하므로 기존 자본시장 규제를 그대로 받는다는 점이 다른 토큰과 가장 큰 차이입니다. 건물·미술품을 잘게 나눠 투자하는 '조각투자'가 대표적인 활용처입니다.

거버넌스 토큰투표권

보유량에 비례해 프로젝트 운영 결정에 참여할 수 있는 토큰입니다. 의결권이 있는 주식과 비슷합니다.

정리

코인과 토큰을 가르는 기준은 자기 메인넷이 있느냐입니다.

구분코인토큰
메인넷자체 보유다른 메인넷 위에 발행
비유나라의 법정화폐나라 안의 상품권·이용권
만드는 법블록체인 네트워크 구축스마트 컨트랙트 배포 (ERC-20 등)
역할네트워크 운영, 수수료 지불서비스가 정한 용도
예시BTC, ETH, ADA, DOTGST, USDT, NFT, 거버넌스 토큰

가상자산 법제화가 진행될수록 이 구분은 "증권인가 아닌가"처럼 더 세밀하고 법적인 기준으로 발전할 것입니다.
