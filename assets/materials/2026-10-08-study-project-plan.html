STUDY PROJECT PLAN

기초 블록체인 스터디 프로젝트 기획안

참여 4명 · 기간 약 8주 · 작성일 2026-10-08

1. 목적

개념 위주로 진행한 스터디를 직접 만들어 보는 단계로 넘깁니다. 블록체인 원리를 코드로 구현하고, 스마트 컨트랙트로 우리 스터디에서 실제로 쓸 서비스를 만들어 테스트넷에 배포합니다.

목표

  • 해시 체인과 PoW가 위변조를 막는 원리를 코드로 이해
  • Solidity로 컨트랙트 작성, 테스트, 배포까지 직접 해보기
  • 지갑을 연결하는 DApp 하나를 4명이 함께 완성

원칙

  • 실제 자산은 쓰지 않고 Sepolia 테스트넷만 사용
  • 매주 1회 모여 진행 상황 공유 + 코드 리뷰
  • 결과물과 회고는 이 블로그에 글로 남기기

2. 로드맵

기간프로젝트배우는 것
1~2주미니 블록체인 직접 만들기 (Python/JS)블록 구조, SHA-256 해시 체인, PoW 채굴, 체인 검증, 노드 동기화
3~4주Solidity 기초 + 스터디 토큰(ERC-20) / 수료 NFT(ERC-721) 발행Remix, OpenZeppelin, 토큰 표준 인터페이스
5~7주스터디 출석·벌금 DApp 메인예치·출금, 권한 관리, 테스트 코드, 프론트에서 지갑 연결
8주~Ethernaut 보안 문제 풀이재진입 공격 같은 컨트랙트 취약점, 매주 한 문제씩 풀이 발표

3. 메인 프로젝트: 스터디 출석·벌금 DApp

출석을 컨트랙트에 기록하고, 결석하면 예치금에서 벌금을 차감합니다. 매주 우리가 직접 쓰는 서비스라서 동기부여가 되고, 예치·출금·권한 관리 같은 핵심 패턴을 모두 다룹니다.

① 멤버 등록 + 예치금 입금→ ② 회차별 출석 체크→ ③ 결석 시 벌금 차감→ ④ 종료 후 잔액 정산·출금

역할 분담

  • A · 컨트랙트: Solidity로 출석·벌금·정산 로직 작성
  • B · 테스트: Hardhat/Foundry 테스트, 예외 상황 검증
  • C · 프론트: 지갑 연결, 출석 현황 화면
  • D · 배포·문서: Sepolia 배포, README, 회고 글

역할은 단계마다 돌아가며 맡아 모두 전 과정을 경험합니다.

완료 기준

  • Sepolia에 배포한 컨트랙트로 실제 1회 이상 출석 체크
  • 핵심 함수 테스트 통과 (입금·출석·벌금·출금)
  • 운영자만 출석을 기록할 수 있도록 권한 제한
  • 스터디 종료 시 4명 모두 잔액 출금 성공
