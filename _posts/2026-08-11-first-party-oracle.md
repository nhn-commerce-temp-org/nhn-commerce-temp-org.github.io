쟁글 아카데미 「오라클 ③」([원문](https://xangle.io/research/detail/783))을
기반으로, 데이터 제공자가 중간 노드 없이 직접 체인에 데이터를 올리는
퍼스트파티 오라클의 개념과 대표 프로젝트의 최신 현황을 정리했습니다.

핵심 요약:

- 오라클: 외부 정보를 모르는 블록체인에 가격·환율 같은 바깥 데이터를 전달하는 역할
- 써드파티 오라클의 한계: 데이터 제공자와 노드 운영자가 나뉘어 수익을 나눠야 하는 "중간 마진" 문제
- 퍼스트파티 오라클: 데이터 제공자가 직접 게시, 스테이킹·슬래싱으로 거짓 데이터를 억제
- 장단점: 수익성과 속도는 좋아지지만, 소수 제공자에게 신뢰가 몰리는 중앙화 위험이 커짐
- Pyth Network: Pull 방식 실시간 가격, 120여 곳의 데이터 제공 기관, OIS 스테이킹(부정확한 데이터에 5% 슬래싱)
- API3: 데이터 제공자가 직접 운영하는 피드, OEV 경매 수익의 80%를 dApp에 재분배
